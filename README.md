# Sistema de gerenciamento de brinquedos
### Por Roberto Stockhausen Hille
Isso é um sistema feito como uma recuperação a atividade 8 (Caça aos erros em PHP).
É um sistema CRUD simples de gerenciamento de brinquedos. Cada brinquedo possui um id, nome, categoria, faixa etária (se é adequado ou não para menores de 3 anos), preço e estoque.
Por ser um CRUD, no index.php é possível ver todos os brinquedos cadastrados, editá-los (que leva  a outra página semelhante a de cadastro), excluí-los e cadastrar novos.
O sistema tem apenas CSS simples, e possuí algumas validações básicas em html, além de prepared staements.

Para executar o projeto, clone o repositório em uma pasta e leve-a para dentro da pasta "htdocs", na pasta do xampp, que fica normalmente no disco C:. Inicie o xampp com apache e mysql (Ou talvez até outro método de gerar um servidor local com banco de dados) e utilize-o entrando na url do seu navegador equivalente ao servidor local.
